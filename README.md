# Implementacja Algorytmów Kolejkowania i Zastępowania Stron

Projekt zawiera implementację czterech popularnych algorytmów wykorzystywanych w systemach operacyjnych do zarządzania procesami oraz pamięcią (zastępowanie stron).

## Zaimplementowane algorytmy

W repozytorium znajdują się kody źródłowe dla następujących algorytmów:

1.  **FIFO (First-In, First-Out)**
    * Algorytm "Pierwszy przyszedł, pierwszy wyszedł". Obsługuje zadania w kolejności ich nadejścia.
2.  **LFU (Least Frequently Used)**
    * Algorytm "Najrzadziej używany". Usuwa z pamięci elementy, do których odwoływano się najrzadziej.
3.  **FCFS (First-Come, First-Served)**
    * Algorytm planowania czasu procesora, działający analogicznie do FIFO (obsługa w kolejności zgłoszeń).
4.  **LCFS (Last-Come, First-Served)**
    * Algorytm "Ostatni przyszedł, pierwszy wyszedł" (stos). Zadanie, które pojawiło się jako ostatnie, jest obsługiwane jako pierwsze.

## Struktura projektu

* `Kody/` - folder zawierający pliki źródłowe z implementacjami poszczególnych algorytmów.
